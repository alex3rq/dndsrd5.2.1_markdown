## Secciones clave por capítulo

### 01 — Cómo jugar
`El ritmo de juego` → `Las seis características` → `Las pruebas con d20` → `Competencia` → `Acciones` → `Interacciones sociales` → `Exploración` → `Combate` → `Daño y curación`

### 02 — Creación de personajes
`Elegir una hoja de personaje` → `Crear tu personaje` (pasos 1-5) → `Progresión de niveles` → `Comenzar en niveles superiores` → `Multiclase` → `Bagatelas`

### 04 — Orígenes de personaje
`Trasfondos de personaje` → `Soldado` (trasfondo de ejemplo) → `Especies de personaje` (rasgos de todas las especies)

### 05 — Dotes
`Descripciones de dotes` → `Dotes de origen` → `Dotes generales` → `Dotes de estilo de combate` → `Dotes de don épico`

### 06 — Equipo
`Monedas` → `Armas` → `Armaduras` → `Herramientas` → `Equipo de aventureros` → `Monturas y vehículos` → `Gastos relativos al nivel de vida` → `Asalariados` → `Lanzamiento de conjuros` → `Objetos mágicos` → `Fabricar`

### 08 — Glosario de reglas
`Convenciones del glosario` → `Definiciones de las reglas` (A–Z)

### 09 — Herramientas del juego
`Ritmo de viaje` → `Crear un trasfondo` → `Maldiciones y enfermedades mágicas` → `Efectos ambientales` → `Miedo y estrés psicológico` → `Veneno` → `Trampas` → `Encuentros de combate`
